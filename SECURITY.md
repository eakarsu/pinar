# Security and representation boundary

Do not enter credentials, API keys, personal data, or payment data into this static reference. It has no server-side processing, authentication, authorization, persistence, integrations, or incident-response operator.

The production artifact makes archived content inert, replaces remote image/font dependencies with local assets, publishes a restrictive content-security policy, and binds the supported preview to loopback. These controls reduce accidental interaction; they do not make the archived product claims, identities, legal text, or intellectual property authoritative.

Public deployment is prohibited until a named owner resolves provenance, license permission, trademark/content rights, security-patching responsibility, and the intended product boundary. A future decision to create a real application requires a separately reviewed implementation of identity, tenant roles, durable storage, migrations, backups, privacy controls, audit evidence, service failure handling, observability, and end-to-end browser tests.

Report a suspected repository vulnerability privately to the accountable repository owner through the source-hosting platform. Do not place secrets or personal data in an issue, test fixture, screenshot, or reproduction.
